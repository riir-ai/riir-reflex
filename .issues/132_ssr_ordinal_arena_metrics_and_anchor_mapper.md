## Item A — ordinal arena metrics (KS on sst5 + per-case Spearman ranking axis)

- [ ] **A1 — per-suite distributional-similarity axis.** For ordinal suites (sst5; add others only when an ordered-label suite actually exists in the registry): per-lane `KS_sim = 1 − sup_r |F_gold(r) − F_pred(r)|` over the aggregate label distribution. **Unordered suites get a SEPARATELY-LABELED total-variation axis** (`TV = ½ Σ|p_gold − p_pred|`, order-free) — never one pooled "KS" column across ordered and unordered label sets (a cumulative statistic is meaningless on unordered labels: it changes under any reordering). The harness reports top-1/ECE today; this adds the realism axis the paper demonstrates catches "regress to suite prior" lanes that look fine on accuracy (the zero-demography persona: KS 0.91 with no ranking signal).
- [ ] **A2 — within-suite ranking axis (per-case, sst5).** Per lane on sst5: Spearman between the lane's expected label `E[r] = Σ_r r·p(r)` and gold, over cases, with a bootstrap CI. ⚠ **Adaptation finding recorded at filing:** the paper's correlation ATTAINMENT (ρ = E[R_xy]/E[R_xx] over 57 concepts) has NO valid between-suite adaptation here — the harness holds one ordinal suite (one point to correlate), and under any between-suite design the suite-prior sampler reproduces each suite mean BY CONSTRUCTION (ρ ≈ high, control untestable). So no ρ ratio is claimed; if a ceiling is wanted, the underlying SST corpus's phrase-level sentiment scores are the natural one — USE IT ONLY IF the harness datasets actually carry them (verify at implementation; expected: label-only → raw Spearman + CI, ceiling dropped, no invented split-half retest from single-label gold).
- [ ] **A3 — tables + gates.** Extend the harness's per-suite output tables (both host republish path via `publish_bench.py` stays the standing law) and add the metric to the lane-comparison rendering. Report-only: no serving-path change, no exit-code change. CI lane regenerates tables (the standing published-tables discipline).
- [ ] **A4 — falsification arm (rewritten round 1).** A synthetic lane sampling labels from sst5's gold marginal must show HIGH `KS_sim` AND Spearman ≈ 0 (CI covering 0). Either half failing = the metric implementation is broken (a red, never a finding about lanes). Do NOT port the paper's between-concept attainment test here — under that design this control passes by construction (that is exactly why A2 dropped the ratio).

## Item B — opt-in anchor-similarity mapper for free-text hosted lanes

- [ ] **B1 — anchor-pmf mapper (transcribe, do not import).** Module behind an opt-in flag: K ordinal anchor statements (one per label level, the paper's short/generic/semi-in-between design + multi-set averaging), embed via an available lane embedder (the lanes precedent — laya or the Bonsai DenseEmbedder trait; pick one, document the choice), cosine → `p(r) ∝ γ_r − γ_min (+ εδ)`, optional temperature, multi-set mean. ⚠ **Scope pinned at filing: sst5-level anchors ONLY.** Unordered suites have no ordinal anchors to define — mapping free text onto them would be plain zero-shot embedding classification, which is the PUBLISHED prior art (Research 020 §2: OpenAI cookbook 2022, Schopf et al. 2211.16285) and explicitly out of this issue's scope. ⚠ Sigmoid-law note (from the research note §5a): Eq. 8–9 is softmax-family over min-shifted cosines; implement as per-level sigmoid gates + renormalization OR document the pmf exception in the module doc — decide at implementation, record either way.
- [ ] **B2 — the abstention leg is load-bearing (the reflex-native delta).** When the anchor cosine spread `(γ_max − γ_min)` is below a floor or the winning mass is below a bar, the mapper ABSTAINS (counted refusal — the exact-match law's honesty in latent form), never emits a near-uniform pmf as a confident map. Thresholds are fit-per-suite calibration constants (the fused-gate cal-fit law: they do NOT transfer; fit at cal, never reuse across suites).
- [ ] **B3 — measured against the exact-match law, opt-in only — WITH A FIRM STOP.** On captured free-text answers (PAW lane captures if available; else a small captured set from any free-text lane), report map-rate and mapped-accuracy: exact-match law vs anchor mapper. The exact-match law stays the DEFAULT; the mapper arms only behind the flag. The honest comparison cell: coverage gained × accuracy preserved. **STOP CONDITION: if no captured free-text answers from an ordinal (sst5-shaped) lane exist when someone claims this item, B closes NO-GAIN — do not build a synthetic lane or a new hosted-spend capture just to give the cell data** (the paper's own result is already the record; a manufactured cell measures the harness, not the mapper). If the mapper maps more but scores worse than exact-match on the mapped subset, that IS the verdict (no-gain close, same shape).
